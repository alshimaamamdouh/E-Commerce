adding static files:
make a folder called static inside your project
then add to settings.py
STATIC_URL = 'static/'
STATIC_ROOT = os.path.join(BASE_DIR, 'static')
STATICFILES_DIRS = [
    os.path.join(BASE_DIR, 'path of static file'),
]

then run "python manage.py collectstatic"
in html use this
{% load static %}
<link rel="stylesheet" href="{%static 'path of css file'%}">

any change in static make it in the original one then run collectstatic to be moved in the system static file
